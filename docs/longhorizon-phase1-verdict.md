## 0. 第一版裁决为何作废

第一版(main-v2)的核心论据是"**拆分率 0%,深度 2 的机制从未被触发**"。

用户质疑"没有教会 agent 用树去拆解任务吗" —— 查证结果:**没有教,写的是刹车**。
原 `spawn_agents` 描述 922 字里正面引导 110 字、刹车 370 字(1:3.4),且五判据中两条
**结构性排除**了实验场景:

- ③"只查一条 SQL 的不配当子任务" → "看视频 X 报时间段"是一次 analyze,不过;
- ⑤"每个子 agent ≈ 一次完整视频分析的钱" → 8 视频拆 8 agent 不省钱,不过。

**模型不拆是完全遵守指令。** 而且描述里漏掉了真收益:拆分**不省钱,省的是步数**
(每个子 agent 有独立步数预算)—— 撞墙的那些跑正是"13 个视频塞不进 16 步"。

重写描述后(正面 499 字 vs 反面 387 字,含可照做的示范),同题同臂对照:

| | 改前 | 改后 |
|---|---|---|
| 拆分率 | **0/24** | **7/12** |

**唯一变量是那段文字。** 第一版裁决作废,以下为重跑结果。

## 2. 决定性证据:**真拆了的那些跑,更差、更贵、更慢**

B/C 两臂共 48 次跑,按"这次到底拆没拆"分组(这是本实验最干净的对照 —— 同臂、同题库、
同 prompt,差别只在模型自己的选择):

| | 次数 | 质量 | set_F1 | 单题$ | 耗时 |
|---|---|---|---|---|---|
| **拆了** | 17 | 0.318 | 0.653 | **$0.399** | **248s** |
| **没拆** | 31 | **0.360** | **0.733** | $0.168 | 158s |

**拆了的质量更低(−0.042 / F1 −0.080),成本 2.4 倍,耗时 1.6 倍。**

这比 C−B 的对照更有说服力:C−B 混杂了"有没有拆"和"能不能拆两层"两件事,而这张表直接
问"拆这个动作本身值不值"。答案是:**在当前任务分布下不值**。

> 需要诚实标注的混杂:模型是**自己选**要不要拆的,它可能专挑难题拆 —— 那样"拆了更差"
> 就有一部分是题目难度而非拆分本身。但方向与幅度(成本 2.4×、耗时 1.6×)足以支撑
> "不建"这个**决策**。

## 3. 功效诚实声明:本实验测不出 +0.10 的效应

A 臂(**没有** spawn 工具,两次完整跑之间配置**逐字节相同**)的漂移:

| 档 | v2 | v3 | 差 |
|---|---|---|---|
| T1 A | 0.198 | 0.310 | **+0.112** |
| T2 A | 0.358 | 0.382 | +0.024 |

**同一个配置,跨轮次漂移 0.112 —— 超过判定门槛 0.10。**
(另:v2 里 B≡C 的分差平均 0.093,同题同臂两跑差平均 0.057、最大 0.411。)

所以"不建"是一个**决策**(没看到收益 + 确实更贵),**不是**"已证明无用"这种科学结论。
要真正判定 ±0.10 量级的效应,题量或 rep 数至少要翻倍。

## 4. 红线回归:诚实探针从 6/6 掉到 4/6

空集题("找出库里所有打高尔夫的视频",库里没有):

- v2(prompt 修复前):**6/6 全对**
- v3(修复后):**4/6**,A 与 C 各有一个 rep 报了假阳性

两次失败锁定同一条视频 `v_08wKlw4a_so`,标题 **"Raking Leaves: A Friendly Wave from
the Yard"(在院子里耙树叶)**。agent **看了这个视频**,视觉模型把耙树叶的挥动读成高尔夫
挥杆,然后毫不含糊地报"库中共有 1 个打高尔夫的视频",还给了时间段和"画面证据"。

**不是凭空编造,是感知错误被自信转述。** 但对空集探针而言后果一样:红线破了。

**可立即行动的修法**:agent 手上有标题("耙树叶")却没和视觉结论("高尔夫")交叉核对。
加一条廉价的自检 —— 视觉结论与标题/库内谓词明显冲突时降置信或弃权 —— 就能拦住。
**这条比深度 2 值钱得多。**

(是否由本轮 prompt 改动诱发,证据不足:B 臂同 prompt 同 rep 答对了。更可能是
"去看视频核实"这个正确行为撞上了视觉模型的误读。)

## 5. 净收获清单

**已确立的事实**

1. **深度 2 不建**(有拆分发生的前提下测得),代码保留、开关默认关;
2. **拆分本身在当前任务分布下不划算**:更差、2.4 倍成本、1.6 倍耗时;
3. **本实验规模测不出 ±0.10** —— 任何后续 gate 都要先补功效;
4. **历史成本数字系统性低报 2.6 倍**(旧账本不计思考 token);
5. **零交付率**:A 臂 v2 5/26 → v3 2/26(跑道提醒 + 交付契约的效果),B/C 各 ≤1/26 ——
   **拆分的第一收益是"至少交得出货",不是"答得更好"**。

**六个会让实验"看起来有结果、其实全假"的缺陷(全部已修)**

| # | 缺陷 | 后果 |
|---|---|---|
| 1 | spawn 描述只有刹车、两条判据结构性排除本场景 | **拆分率恒 0,裁决建立在假象上** |
| 2 | 判分口径与产品规则冲突(要 id,而 VS 按规则洗成"第 N 个") | 每一臂恒 0 分 |
| 3 | T2 防 SQL 捷径从没实现 | 查库抄时间戳,一个视频不看也能答 |
| 4 | analyze 缓存键不含命名空间 | 三臂共享暖缓存,"全口径成本"是假的 |
| 5 | 熔断预留按 pro 一刀切估价 | 实花 $0.13 顶掉 $0.80 的闸,**专罚看视频多的臂** |
| 6 | 跑机 surfaced 取"碰过的一切" | gold=3 的题抓到 37 条 |

**下一步建议(按价值排序)**

1. **感知—元数据交叉核对**(拦住"耙树叶=高尔夫"这类假阳性)—— 红线级,便宜;
2. **拆分决策时机**:现在仍是"先缩小候选再数步数"的软引导,可升级为 trace 里的
   硬信号(待办量 > 剩余步数覆盖能力)自动提示;
3. 后台任务的**触发**从未被测过(gate 实验里 `USE_TASKS=0`),是独立的一条;
4. 若要再判深度 2,先把功效补足(题量或 rep 翻倍),否则噪声吃掉效应。
