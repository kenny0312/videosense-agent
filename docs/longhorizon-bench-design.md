# VS-LH Bench · 长程多任务基准设计 v1(2026-07-29)

> **定位**:测量"CC 式长程多任务系统"整体能力的冻结基准——树引擎 × 任务底座 × 交互回路一起量。并入总任务书 Part E 作 **E-4**(E-3 的 B1/B2/B3 保持不变;B2 的 18 题被本基准复用为 F1/F2,不重复花钱)。
> **对 ROMA 基准的取舍**:ROMA 的证据全在搜索赛道(SEAL-0:GLM-4.6 裸 14.5→套壳 45.9)+ 长文写作(其论文 Table 5 即在此测得聚合占 40% 成本)。**取**:①任务结构上必须超出单上下文(强制分解+聚合)②检索环境带对抗噪声③复合交付物(带逐项证据的长报告)。**补它四个短板**:①无组件/深度消融 → 我们每个能力族带臂对照;②零成本披露 → 全口径 $ 是一等指标;③judge 自报 → κ≥0.7 校准+对臂盲+冻结;④无弃权测试 → 诚实探针一等公民。

---

## 一、八个任务族(F1-F8)

**语料**:现库 514 条视频快照冻结(与 gate 实验同一快照);gold 构造沿用防作弊双闸先例(盲测必错 + 冻结索引查不到/查不全)。

| 族 | 测什么 | 任务形态(示例) | 判分(确定性优先) | 对应 ROMA |
|---|---|---|---|---|
| **F1 库级清点**(广度) | fan-out 覆盖 | "找出全库所有含 X 的视频,列 id+时间戳+一句证据" | 集合 F1 vs 冻结 gold;时间戳 ±10s/IoU≥0.3;引用真实性 | SEAL-0 搜索赛道的私库版 |
| **F2 深挖聚合**(深度) | 递归增量 | F1 + 每条内部精确定位/分级("每条摔倒定位到秒并评严重度") | F1 + 定位分 + 分级准确率(受控词表) | 同上,加一层 |
| **F3 报告合成**(复合交付) | 聚合与组织 | "出一份剪辑素材推荐报告:分组/排序/每条给理由和时间点" | 确定性骨架检查(gold 集全覆盖/分组合法/时间点可验)0.7 + judge 文本质量 0.3 | EQ-Bench 长文写作的对应物 |
| **F4 事故穿越**(稳健) | 底座韧性 | 同一 F3 任务跑两遍:无事故 vs 注入事故(波 kill/断连/暂停恢复) | **结局奇偶性**(两遍结论一致率)+ 事故开销 Δ$ + 因由码正确(T-2) | ROMA 没有 |
| **F5 中途转向**(交互) | steering 生效 | 任务跑到第 k 波,追加指示改范围("重点改成只看夜间片段") | **trace 断言**:注入后波的子任务受新范围约束(确定性);报告体现两阶段 | ROMA 没有 |
| **F6 并发多任务**(隔离) | 多任务互不踩 | 同时立 3 个任务(1 大 2 小)+ 期间主 loop 照常答 5 道 B1 题 | 全部完成;**逐任务账本互不串且总和=全局账**;主 loop 答题延迟 Δ≤50% | ROMA 没有 |
| **F7 续作迭代**(CC 式) | 基于产出改进 | F3 完成后:"第 3 节细化/按赛事重排" | 报告实际变化(diff 断言)+ **成本 <50% 首作**(缓存命中入指标)+ 父链 trace 可证 | ROMA 没有 |
| **F8 诚实探针**(对抗) | 零编造 | 空集题("找出所有水下潜水视频"——库里没有)+ 相似陷阱题(有滑雪没滑水) | 精确判空=1,编造任何 video_id=0;弃权语句合规 | 补 SEAL-0 弱点 |

## 二、臂设计(修 ROMA 无消融的毛病,但控制预算)

- **F1-F3 跑四臂**(能力轴,要对照):A 单脑同步 / B 一层树同步 / **S1 底座+一层** / **S2 底座+深度2**(S2 仅在 gate 过闸后加)。F1/F2 直接**复用 gate 实验 18 题与其 A/B/C 数据**(已付费),只补 S1/S2 臂。
- **F4-F8 只跑底座臂**(测的是底座性质,无对照意义;F6 的"主 loop 照常"内嵌了对照)。

## 三、指标八件套(每 run 必录,全口径)

质量分 / 全口径 $(含思考 token)/ 端到端时长 / LLM 调用数 / 事故结局奇偶性(F4)/ 交互合规率(F5,trace 断言)/ 账本隔离度(F6)/ 迭代效率比(F7)。副指标:缓存命中率、弃权数、编造数、熔断触发、因由码分布(triage 直出)。

## 四、判分纪律(全套沿用家规)

确定性成分优先(集合/时间戳/trace 断言/账本数学全是代码判);judge 只碰自由文本,κ≥0.7 校准才上岗、对臂盲、temp 0;**题库+gold+judge prompt 冻结,改任何一样 → 全套件重判**;n≥2 翻转单列;Δ 必带 Fisher p + Wilson 区间,p>0.05 写"不足以判定"。

## 五、成本与运行档位

| 档位 | 内容 | 何时跑 | 成本 |
|---|---|---|---|
| **FULL** | F1-F8 全量(F1/F2 复用 gate 数据) | 大版本(如翻 USE_DEPTH2 前后各一次) | ~$25 |
| **LITE** | F4×1 + F6×1 + F8 全部 + B1 冒烟 | 每次发版 | ~$4 |
| 基线快照 | FULL 在开关全关+底座首版上先跑一遍存档 | 底座交付时(一次) | 计入 FULL |

## 六、施工(并入总任务书,+1.5 天)

E-4a 题库与 gold(F3 报告题 3 道 + F5/F7 剧本 4 个 + F8 探针 4 道;双闸预筛)~$1;E-4b 跑批器扩展(run_matrix 模式 + 任务 API 驱动 + trace 断言库——断言直接查 T-2 因由码与 span,**这是观测先行的又一红利**)~150 行;E-4c 判分器扩展(骨架检查/奇偶性/账本数学)~120 行。
**验收**:FULL 一遍全绿出八件套报表;故意注入一个 steering 不生效的 bug,F5 必须红。

## 七、与 ROMA 证据水位的对照承诺

ROMA 最被诟病的是"全自报、无消融、无成本"。本基准的公开报表格式承诺三样它没有的:每族带臂对照(能力增量可归因)、每 run 全口径美元(经济性可复算)、弃权/编造率单列(诚实度可见)。若未来对外发 VS 成绩,以本基准 FULL 报表为准。
